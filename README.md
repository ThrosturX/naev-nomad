# Nomad Fleet

Nomad is a Naev carrier campaign with Mule, Soromid Arx, and Raven Clan Pirate Rhino starts. When More Variants is installed, a mutated Soromid Vox carrier start is also available. Physical bay outfits launch disposable copies of owned craft; returning copies fly back to the carrier, while Joyride handles player-controlled sorties and carrier docking.

The Auxiliary Ship Bay plugin is required because it supplies Joyride. Crewmates is optional: when available it owns the commander and command-shuttle roster; otherwise Nomad launches and persists its own command shuttle through Joyride.

The carrier can be parked in space for equipment and fleet services. Owned ships must fit its installed bays, and incompatible purchases are refunded or offered as carrier replacements. An optional medium Unstable Wormhole Generator can open a temporary route to a nearby system. The carrier stays behind when a bay ship uses it and the route collapses when the commander returns aboard the carrier.

Run `make check` for syntax, manifest, Lua, and LuaJIT validation.
